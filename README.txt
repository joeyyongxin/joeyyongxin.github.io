JOEY CHAN PORTFOLIO WEBSITE

FILES
- index.html: website content and page structure
- style.css: colours, layout, responsive/mobile styling
- script.js: mobile navigation and current footer year

PREVIEW LOCALLY
1. Extract the ZIP file if you downloaded it as a ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Keep index.html, style.css, and script.js in the same folder.

PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a new public repository (e.g. joey-portfolio).
3. Upload index.html, style.css, and script.js to the repository root.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and /(root), then Save.
7. Wait for GitHub Pages to publish the site; the URL will be shown in Settings > Pages.

BEFORE PUBLISHING
- Confirm that the email address is correct and that you want it public.
- Review every date, award, education entry, and job detail.
- The site currently links to email only; it does not publish your phone number or a downloadable resume.
- Google Fonts are loaded online. The page still works without them, using fallback fonts.
