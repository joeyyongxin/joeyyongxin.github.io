Files
- index.html: page content and metadata
- style.css: layout, colours, typography, responsive styles
- script.js: mobile navigation and current year
- resume.pdf: add your résumé PDF here for the Download résumé button to work

Preview
Open index.html in a browser. Keep all files in the same folder.

Publish with GitHub Pages
1. Upload index.html, style.css, and script.js to the root of your portfolio repository.
2. Add resume.pdf to the same folder for the résumé download button to work.
3. In GitHub, open Settings → Pages and publish from the branch and folder containing index.html.
